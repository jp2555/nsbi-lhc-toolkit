ABCD (QCD multijet)

ND = NB · NC / NA 4 orthogonal regions from 2 variables (e.g. charge OS/SS × τ-iso tight/anti); D = signal-like
  • Assumes: the 2 variables factorize for background; composition stable across regions.
  • Gives: yield + coarse binned shape. Not a per-event density.

Fake-factor (jet→τh)

FF = Ntight / (Nloose − Ngenuine) measured in a fake-enriched DR; applied as a per-event weight to AR (loose-not-tight) events
  • Regions: SR (tight) · AR (loose-not-tight) · DR (fake-enriched: SS, or high mT).
  • Assumes: fake composition stable DR→SR. Subtract genuine-τ first. Syst ~10–30%.
  • Gives: per-event weights on a sample. Not an evaluable p(x).

ABCDnn = neural autoregressive flow conditioned on control vars (e.g. Nj, Nb), trained on signal-depleted sidebands, extrapolated to D. Original: max-likelihood (2008.03636). CMS four-top: MMD-trained, yield/shape split (ExtendedABCD yield + ABCDnn shape of BDT+HT). ExtendedABCD there: closure ~18–19% → ~1–7% (illustrative; S. An thesis, internal).

The NSBI link — and the gap

NSBI needs a per-event ratio r(x)=psig(x|κλ)/pref(x) for every component. Data-driven outputs don't supply one:

MethodOutputper-event p(x)?Bridge to NSBI
ABCDyield + histogramnotrain a flow (ABCDnn) → classifier vs ref → r(x)
fake-factorper-event weightsnoneural fake-factor = density ratio FF(x) (2511.06972)
embeddinga samplenodensity-estimate / classifier-to-ref
ABCDnnlearned densityyesclassifier(flow-gen vs ref) → r(x)

Honest gap: ABCDnn deployments target a low-dim object (four-top: BDT+HT, for a binned fit). NSBI wants the full 10+-dim per-event density → high-dim flow (hard), more data, punishing closure tests, + per-event systematic morphing of r(x). No published bbττ NSBI does this yet.

Pragmatic first step: ABCDnn/neural-FF model only the data-driven shape of the 1-D NSBI discriminant; bin QCD/fakes as an auxiliary likelihood term; per-event morph only the MC components (embedded-DY, tt̄, single-H, diboson). (design proposal, not published)
