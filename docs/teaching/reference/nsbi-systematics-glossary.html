NSBI systematics — glossary

Quick reference for Lesson 1. One vocabulary, used consistently.

Core objects
NSBI / SBI
(Neural) Simulation-Based Inference. Estimate per-event likelihood ratios with networks, then do a likelihood fit — no binning into histograms.
Per-event likelihood ratior(x)
The learned object replacing the histogram template: ratio of probability densities for one event x under two hypotheses. Trained as a calibrated classifier.
Parameter of interest (POI)η, μ, κλ
What you measure (signal strength μ; Higgs self-coupling κλ). Has known a-priori dependence in the rate factor.
Nuisance parameter (NP)α, ν, χ
A systematic's continuous knob (tau energy scale, JES, shower model, background norm), constrained by an auxiliary measurement / prior.
Systematic morphingΔs(x|α)
How sample s's per-event density deforms as α varies. The hard, intractable, no-known-form factor every method approximates.
Anchor pointα(i)
A nuisance value where a full simulation exists (often nominal and ±1σ). Δ is known here; you must interpolate between them.
Statistics
Profile likelihood / profiling
Maximize the likelihood over the NPs at each POI value; the resulting curve gives the confidence interval. "Costing" the systematics.
Test statistictμ, qθ
tμ = −2 Δln L profiled over NPs. 68% CI where tμ = 1; 95% where tμ = 3.84.
Systematic inflation
How much the profiled CI widens vs stat-only — the cost of the systematics. Smaller = a more robust analysis.
Constraint termf(a|χ)
The auxiliary-measurement prior on each NP (often Gaussian) multiplied into the likelihood.
Method ideas
Factorizable NP
Its impact factorizes across samples/other NPs (Δ = ∏ of single-NP factors). Traditional HistFactory assumes this; R3/R4 relax it (non-factorizable).
Parametric ansatz
Assume a functional form for Δ(α) (piecewise-linear/exponential, polynomial). Cheap but can be too rigid. R4 makes the ansatz ML-learned & arbitrary-order; R3 drops it for a GP.
Gaussian Process regressionf ∼ GP(m,k)
Non-parametric interpolation that also returns a posterior uncertainty. R3 uses it to model Δ(α) in high-dim with an interpolation error band.
Uncertainty-aware / nuisance-parameterized
Feed α as a network input so the ratio learns the (x, α) correlation, instead of decorrelating from it (R1). Basis for R2–R4.
Pivot / decorrelation
Train a discriminant to be independent of a nuisance. The "robust representation" idea; RS3L is its self-supervised, re-simulation form.
Re-simulation (RS3L)
Re-run shower/hadronization/detector on the same hard event to make contrastive augmentations → a representation insensitive to those systematics.
Joint likelihood ratio
Extra simulator-truth information (e.g. per-event weights) used to train ratio estimators more efficiently (exploited by R4).
Classifier Two-Sample Test (C2ST)
Train a classifier to tell learned-vs-true samples apart; near-chance AUC ⇒ the surrogate is faithful. R4's validation.
Tools / benchmarks
HistFactory / pyhf
The standard binned-template likelihood. "v2" = the GP-morphing generalization (R3).
GOLLUM
The unbinned-ML-systematics fitting framework used in R4's FAIR Universe study.
FAIR Universe
Tabular H→ττ vs Z→ττ/tt̄ benchmark with real TES/JES/soft-MET/bkg-norm nuisances; the shared testbed (also yours).
